# Application icon

Original project artwork generated with the built-in Imagegen tool. No vendor logos are used. `AppIcon.png` is the source; the package script builds all macOS icon sizes and `AppIcon.icns` from it.

## Generation prompt

Use case: logo-brand. Asset type: polished macOS application icon for a racing wheel force feedback bridge. Create a single premium macOS rounded square app icon, front view, isolated with genuinely transparent pixels outside the rounded square. A bold sculpted three-spoke racing steering wheel centered on a deep graphite squircle tile, metallic satin finish, crisp luminous electric cyan accents on the wheel and two restrained curved force-feedback arcs. Sophisticated dimensional soft studio lighting, strong readable silhouette at small sizes, generous consistent macOS icon outer padding, perfectly centered. No text, letters, brand logos, NVIDIA or Fanatec trademarks, no mockup device or extra background. Square 1024x1024.
